## ⚡ En Bref : Les Thèmes KaïroOS

- **Zéro couleur en dur** : Tous les composants injectent dynamiquement les variables CSS déclarées dans `theme.json`.
- **3 Layouts Officiels Fournis** :
  - `kairo-default` : Layout Arcade Classique (sidebar gauche + grille dynamique)
  - `kairo-hub` : Layout Plein Écran Catégories (rayonnages horizontaux)
  - `kairo-console` : Layout Console TV / Steam Big Picture (Hero showcase + carrousel centré)
- **Raccourci d'Urgence** : Touche <kbd>Suppr</kbd> / <kbd>Del</kbd> sur clavier réinitialisant instantanément le thème officiel de secours.

Pour explorer les thèmes officiels, tester le simulateur de shaders CRT et soumettre vos thèmes :
