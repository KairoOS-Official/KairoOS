## 📍 Résumé des Jalons

- **v0.1.0 Alpha (LIVRÉ & VALIDÉ)** : Core Rust autonome, SQLite `kairo.db`, Frontend React 19 + Tauri 2, navigation 100% manette, 3 thèmes structurels, PWA remote.
- **v0.2.0 Bêta (EN COURS)** : Scraping ScreenScraper HD, multi-disques `.m3u`, overlay in-game transparent, moteur de shaders CRT.
- **v0.3.0 (PLANIFIÉ)** : Succès RetroAchievements, synchronisation Cloud des sauvegardes, temps de jeu.
- **v1.0.0 (VISION)** : Extensions universelles (stdin/stdout JSON), mode Kiosk blindé, support multilingue intégral.
